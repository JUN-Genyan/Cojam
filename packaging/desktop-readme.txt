合拍 Cojam Windows 桌面版
==========================

用法
----
1. 把整个文件夹解压到一个固定位置（不要在压缩包里直接运行）。
2. 双击 Cojam.exe，会直接出现标题为「合拍 Cojam」的应用窗口。
3. CojamCore.exe 是后台服务，不用单独双击；排障时可在命令行运行它。

说明
----
- Cojam.exe 是窗口入口；CojamCore.exe 是会议后台。两个文件必须放在同一个文件夹。
- 会话和配置保存在安装目录的 data 文件夹。覆盖安装或卸载时会保留该文件夹。
- 需要 Microsoft Edge WebView2 运行时（Windows 10/11 一般已经安装）。
- 找不到 CojamCore.exe、端口被占用或后台启动失败时，会弹出提示。
- 桌面窗口打不开时，会自动改用浏览器打开合拍。
- 关闭最后一个合拍页面后，后台约 6 秒退出；还有任务运行时，关闭窗口前会先确认。
- 浏览器页面和桌面窗口可以同时使用，关闭其中一个不影响另一个。
- 需要把其他设备的 Harness 接进来时，双击「连接其他会议室.bat」。
