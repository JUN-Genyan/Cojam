# 应用内 Agent 设置

联系人栏点击「管理」，可管理全部已有 Agent，包括暂时未找到程序的联系人。点击侧栏里的 Agent 也会直接打开设置页；首次添加仍使用「＋ 接入」。所有设置都用表单、选择框和勾选项编辑，无需手动修改配置文件。

## 可以修改什么

- **基本**：联系人名称。联系人 ID 保持不变，已有会话和 @ 引用不受重命名影响。HTTP 联系人还可修改服务地址；原有服务凭据保留。
- **CLI**：程序路径和备用命令，按顺序查找；桌面窗口支持系统文件选择器，浏览器可填写运行合拍的电脑上的完整路径。启动参数逐项添加或删除，含空格的参数直接填写，不需要额外加引号。通用 CLI / ACP 还可调整新建、续接、模型、effort 等参数，以及提示词、上下文传递方式。Claude/Codex 保留原有协议参数，仅开放附加启动参数。
- **桌面 / MCP**：桌面程序位置、宿主类型、MCP 保存位置。先保存偏好，再使用「保存并应用 MCP 配置」由应用写入；原宿主配置会备份。已有密钥需要明确勾选更换，在线成员需先停止待命。失败时保留原文件和密钥。写入完成后仍须重启软件并手动开启 `/cojam_standby`，配置存在不等于模型正在接单。
- **模型**：默认模型和 effort；可补充模型索引并勾选每个模型支持的 effort。选择模型后 effort 联动；模型不支持 effort 时不保留旧强度。此处配置是联系人默认值，会议中单独选择的模型和 effort 优先。
- **加入会话**：新建会话时默认是否勾选，以及新加入会话的默认权限。已有会话单独列出，可以调整此联系人是否加入及其权限，不覆盖其他成员。

## 保存与生效

保存后可关闭并重新打开设置，继续修改。程序位置和默认值用于后续调用；涉及该 Agent 的会话正在执行或排队时，后端拒绝修改，等待任务结束后再保存。其他窗口同时修改过配置时提示重新打开，不覆盖新值。

修改程序位置后仍可从「设置」列表找回联系人，即使新位置暂时不可用。CLI 验证证据会随程序和参数变化失效；重命名、修改默认加入规则不需要重新验证程序。

新建会话会预选默认联系人，仍可手动取消或创建空会话。调整默认权限不追溯覆盖已有会话的授权。原有会话 ID、模型会话、已保存的会议专属设置和联系人凭据不会因普通保存而重建。

填写模型索引不代表客户端增加了模型控制接口或账户获得了模型权限。不能控制的桌面端仍可参与，界面说明具体限制。ACP 明确拒绝模型或 effort 设置时，本轮停止并返回错误，不静默换回默认模型。

会议中的「执行端」提供独占接管与同一原生会话续接；模型面板提供索引刷新、设置应用状态和实际回报，详见 [执行端与模型](AGENT_EXECUTION.md)。保存桌面位置本身不会切换执行端。桌面启动自动待命按本次约定暂缓；普通 MCP 未提供模型写入接口时限制控件并保留接入。

## 验证

新增的 `tests/test_agent_settings.py` 覆盖重复编辑、内置 Agent 路径与默认值进入实际调用、默认加入及权限、并发版本、写入失败、MCP 配置回滚和凭据隔离；桌面壳测试覆盖程序文件选择和取消。ACP 回归覆盖配置拒绝和应用状态失效。

独立测试数据的 Chrome 页面验证覆盖保存后重开、默认模型/effort 联动、程序路径失效后恢复、会话权限、移动端布局以及首次接入参数表单；不触碰真实联系人、MCP 文件或收费模型。

2026-11-13 最终验证：完整隔离回归 374 项通过，后续补充的扫描、界面及远端模型重置回归通过。Windows 子进程停止和取消测试在沙箱外运行，避免沙箱限制被误判为应用故障。最终验证范围见 [执行端与模型](AGENT_EXECUTION.md)。
