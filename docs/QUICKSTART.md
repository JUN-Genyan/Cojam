# 合拍新手使用说明

适用于合拍 2.6.10 Windows 桌面版。照着下面操作，可以先建一场会话，再把 AI 或朋友请进来。

## 先认识三个词

- **联系人**：可以邀请进会话的 AI 或其他人。联系人在左上角。
- **项目**：用来归类会话，并指定一个工作文件夹。
- **会话**：大家一起聊天、讨论和协作的地方。一个项目可以有多个会话。

## 第一步：下载安装

1. 打开[合拍官网](https://jun-genyan.github.io/Cojam/)，找到「Windows 桌面版」，点击「下载安装程序」。
2. 打开下载的安装程序，按照提示完成安装，然后打开「合拍 Cojam」。
3. 安装版不需要另外安装 Python。安装包目前未签名，Windows 或浏览器可能显示安全提示。

如果不想安装，也可以在官网下载「Windows 便携版（浏览器）」，双击后在浏览器里使用。便携版的数据保存在程序旁边的 `data` 文件夹。

Mac 桌面版目前提供源码运行和本机构建方式，尚无这里介绍的 Windows 安装包；见 [macOS 使用说明](MACOS.md)。

## 第二步：创建项目和会话

1. 在左侧「我的项目」旁点击 **＋**；也可以点击左下方的 **＋ 新建会话**，按提示先创建项目。
2. 填一个项目名称，例如「我的网站」。
3. 选择一个**已经存在**的工作文件夹，例如 `D:\我的网站`。这是这个项目的 AI 工作位置；先建立空文件夹也可以。
4. 点击「创建项目」，再填写会话标题，例如「讨论首页设计」。
5. 如果已经添加过联系人，可勾选想邀请的成员；也可以先不选，创建空会话。
6. 点击「创建会话」。右侧出现聊天界面，就可以开始了。

> 手机或窄屏设备上，先点左上角的 **☰** 打开左侧导航。

## 第三步：连接本机 AI

以 Codex 或 Claude Code 为例：**先在这台电脑安装并登录对应的命令行程序**。合拍不会替你安装、登录 AI，也不包含它们的使用额度。

1. 点击左侧联系人旁的 **＋ 接入**。
2. 选择 **连接 AI → 本机 Agent**。
3. 在「选择程序」里选择标有「已检测到」的 Codex、Claude 或其他程序。
4. 点击 **检测并验证程序**，等待验证结果。这里检查的是程序能否启动；是否已登录、有无额度，仍要以实际回复为准。
5. 验证成功后点击 **下一步：会话与权限**，选择刚才创建的会话，按需设置权限。
6. 点击 **保存并加入会话**，再点击「进入会话」。

现在可以在输入框输入 `@codex 你好，请先介绍一下你能做什么`，点击「发送」。其他 AI 用联系人列表中显示的 `@名称`。不写 @ 时，会默认叫当前会话里的全部 AI。

**找不到程序？** 先确认程序已经安装并登录，再完全退出合拍后重新打开；也可以在「选择程序」中选「自定义 CLI 程序」，填写命令或完整路径。如果程序验证通过但不回复，先到它自己的终端检查登录、网络和额度。

## 邀请朋友一起聊天

适合让朋友以**自己的身份**加入某一场会话。

1. 点击 **＋ 接入 → 邀请其他人**。
2. 在「会话」中选择要邀请朋友加入的会话，检查显示的权限。
3. 查看「邀请地址」：这个地址必须是**朋友的设备也能打开的地址**。同一 Wi-Fi 时通常可使用显示的局域网地址；`127.0.0.1` 只表示本机，朋友打不开。
4. 点击 **生成邀请**，把链接或二维码发给朋友。
5. 朋友在自己的手机或电脑上打开链接，按页面提示加入。只把邀请发给信任的人。

邀请或二维码是否能用，取决于双方网络和防火墙；不在同一网络时，需要提前准备双方都能访问的地址，合拍不会自动打通网络。

## 在自己的手机或另一台电脑上使用

如果是**你自己的设备**，希望它以“我”的身份使用完整界面：

1. 点击 **＋ 接入 → 我的设备**。
2. 填写设备名称，选择对方能访问的接入地址。
3. 点击 **生成设备接入码**，用自己的另一台设备扫码或打开链接。
4. 接入码 10 分钟内有效、只能使用一次。接入后可在此页面查看或撤销设备。

同一浏览器和同一地址会保存设备凭证；Cookie 丢失时可用已保存的凭证恢复。请保存稳定、在外也可访问的地址；换域名、换浏览器、清除网站数据或使用隐私浏览后，浏览器的保存数据不能自动跨地址或环境共享。连接仍要求电脑上的合拍后台运行且网络可达。

其他设备不能指定电脑上的文件夹来新建项目；手机网页不支持用本地文件夹创建项目。已有会话仍运行在原电脑上，不应把「我的设备」视为已隔离的文件权限。

「我的设备」会获得完整界面和你的身份；**不要把这个接入码发给朋友**。邀请朋友请使用上面的「邀请其他人」。

## 让另一台电脑上的 AI 参加

1. 点击 **＋ 接入 → 连接 AI → 其他设备上的 Harness**。
2. 填写联系人名称，选择「自动接收任务并回复」，填写对方能访问的接入地址。
3. 点击 **生成连接配置**，下载页面提供的「成员连接端」和该成员的连接配置；只通过可信方式发给对应的人。
4. 对方解压成员连接端并启动：Windows 运行 `start-member.bat`；Mac 运行 `start-member.command`，需要 Python 3.11 和 Tk。
5. 对方导入连接配置，选择自己电脑上的 AI 和工作文件夹，点击 **连接并开启自动响应**。
6. 合拍显示「自动响应已连接」后，点击 **下一步：会话与权限**，选择会话并保存。

每台电脑使用各自的工作文件夹，文件不会因为接入而自动同步。连接配置含密钥，不要公开分享。

## 日常怎么用

- **发消息**：在底部输入内容，点击「发送」。点击回形针可以添加附件。
- **换会话**：在左侧项目下面点击会话名称。顶部「成员与权限」只修改当前会话。
- **讨论和干活**：顶部可切换模式。讨论适合先商量；干活模式可能让 AI 修改文件、运行命令和联网，切换前先看提示并确认工作文件夹。成员还需要开启「允许干活」权限。
- **删除联系人**：在左侧自建联系人旁点击 **×**，或点联系人栏的 **⋯** 管理。若提示联系人仍在会话中，先在相关会话的「成员与权限」中移除，再删除。
- **退出**：左下角点击「退出」。还有任务运行时，先等任务完成，或确认中断后再退出。

## 常见问题

**AI 没有回复怎么办？**

先检查该 AI 是否在当前会话的「成员与权限」中；发送时用列表里显示的 `@名称`。再检查它是否已安装、登录和有可用额度。若接的是另一台电脑上的 AI，还要确认对方的成员连接端显示自动响应已连接。

**朋友打开链接失败怎么办？**

确认你的合拍仍在运行，邀请没有过期或被撤销，地址不是 `127.0.0.1`。同一 Wi-Fi 下检查双方是否真的在同一网络、Windows 防火墙是否允许访问；跨网络需要双方都能访问的地址。

**更新后会话还在吗？**

桌面安装版的会话和配置保存在安装目录的 `data` 文件夹。更新前退出合拍，并安装到原来的目录；安装到新目录不会自动搬迁旧数据。重要会话建议先备份整个 `data` 文件夹。

**怎么更新？**

点击左下角 **更新**。Windows 桌面安装版可选择 **下载并更新**：合拍会校验安装包、在任务空闲时关闭并安装，然后重新打开。便携版或其他不支持自动安装的环境可下载安装程序后手动运行。也可以从官网下载新版。

**还是卡住或打不开？**

先退出合拍并重新打开。如果仍有问题，记下你正在点击什么、出现的提示以及版本号；在安装目录的 `data` 中查找 `cojam.log` 可帮助排查。日志可能包含私人信息，分享前先检查。
