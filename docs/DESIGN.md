## 2.4.3 · 2026-11-03 · Studio 重设计

接入方式在桌面重排为四张双列卡片，配套同一笔画规格的矢量图标；手机改为紧凑单列。访客入口、PWA、离线提示和 Windows 图标一起更新。主样式集中在 `static/studio.css`，不继续堆叠旧视觉规则。浅深色模式、减少动态设置与弹窗键盘行为保留。网络及接入能力未改变。

## 2.4.2 · 2026-11-03

按用户指定，以数学符号「∀」与「∫」组合为应用标识。设计寓意：每个独立成员都能参与，将不同成员的讨论汇集到同一个协作空间。寓意是品牌诠释，不是数学公式。保留 AI Bridge 名称。

标识采用暖白的 ∀ 和浅绿的 ∫，深青色圆角底板。在 16–512 像素下保持简单、可识别；`make_icon.py` 统一生成 `static/logo.svg`、Windows ICO 和 PWA PNG。矢量是界面标识，ICO 是 exe 图标，maskable 图标保留裁切安全区。修改后运行 `python make_icon.py`；Windows 构建也会自动重新生成。

主界面继续采用用户确定的左侧全局联系人、项目与会话树，右侧选定会话。导航底部提供新建会话入口与本机托管说明。会话头部展示项目、会话名及受邀成员数；成员数不表示在线人数。联系人保持明确的未验证、未找到程序或实际连接状态。

暖白、灰绿与深青用于减轻长时间阅读负担；深色模式跟随系统。减少工具栏视觉权重，突出成员与权限；收窄消息阅读宽度，统一输入区、附件按钮、@ 快捷操作。空会话有文字提示。接入向导、网页访客入口和离线提示共享同一套品牌与配色。

手机通过抽屉打开导航，平板与桌面适配各自空间；弹窗支持 Escape、键盘焦点限制和关闭后返回触发按钮。尊重系统减少动态效果设置。

主应用发行包不再嵌套成员连接端 ZIP；独立连接端继续由接入向导按需下载。接入协议和网络条件未改变：跨设备仍需可达地址，没有新增扫码配对或自动中继能力。
