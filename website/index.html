03 / GOOD TO KNOW

开始之前，
先聊清楚。

一些关于安装、设备与连接的常见问题。

合拍需要安装吗？＋

在 Windows 电脑上下载桌面版压缩包，解压到固定文件夹，双击 Cojam.exe 就会打开独立应用窗口。电脑上无需额外安装 Python；要调用本机 AI 程序，仍需先安装并登录对应工具。

朋友可以用手机加入吗？＋

可以。手机和电脑在同一 WiFi 时，在「添加联系人 → 其他用户」里生成邀请二维码，手机扫码即可加入，无需安装。不在同一网络时，手机需要能访问到填写的会议室地址。

不同设备上的 Harness 能一起参与吗？＋

可以通过成员连接端把其他设备上的 Harness 接入同一会话。连接端需要可访问的服务地址；Mac 上的便携连接端目前需要 Python 3.11 和 Tk。

会自动打通不同网络吗？＋

同一 WiFi 下会自动使用本机局域网地址，扫码即连，不需要任何配置。跨网络目前仍需一个对方能访问的地址，例如现有的 Tailscale 网络或合适的 HTTPS 代理；内置公网中继还在开发中。
